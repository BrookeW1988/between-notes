# Contributing

Small, readable contributions are welcome. Open an issue describing the problem before proposing a large change.

Use fictional examples only. Never put real client notes, names, screenshots, restoration maps, medical records or credentials in issues, pull requests, logs or test fixtures. Reduce a bug to a minimal invented example.

1. Fork the repo and create a branch.
2. Follow the setup instructions in README.md.
3. Add a focused regression test for a behaviour change.
4. Run the Python and JavaScript tests and describe what you tested.
5. Open a pull request with the problem, changed behaviour and any limitations.

Preserve local processing, exact restoration and clinician review. Do not add telemetry, external model calls or persistent client storage without discussing the privacy model first. Detection rules should document false positives as well as missed identifiers. Describe OCR limitations rather than claiming perfect extraction.

Contributions are provided under the repository's MIT licence. Third-party dependencies keep their own licences.
