# Security and privacy

This is an experimental, single-user local prototype. It is not approved or validated for real clinical records. Never expose its Flask server to the internet or a shared network.

Report a suspected vulnerability using only a fictional reproduction. If GitHub's private vulnerability reporting is enabled, use the repository's Security tab to report privately. Otherwise, open an issue requesting a private contact without publishing exploit details or sensitive data.

Do not attach real client material, credentials or restoration maps. An issue tracker is public, and deleting a post does not reliably remove copies.

The tool reduces direct identifiers but cannot guarantee anonymity. Context can still identify someone, OCR can be wrong and an AI response can invent facts. See README.md for the data flow and operational limitations.

There is no guaranteed response time or production support agreement for this community prototype.
